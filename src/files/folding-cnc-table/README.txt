Folding CNC table — CAD backup
==============================

Parametric FreeCAD builder for a folding CNC spoilboard cart.
Default top: 1220 x 1830 mm, 70 mm thick. Plywood: 17 mm.

Files
-----
folding_table.py     Edit CONFIG at the bottom, then run in FreeCAD.
FoldingTable.FCStd   Last rebuild from that script.
TableComplete.FCStd  Original source model (not edited).
CUT_LIST.txt         Quantities and DXF names.
dxf/                 Per-part DXFs plus folding_table_sheet.dxf.

Interactive model on the site:
https://unclemikesgarage.com/apps/folding-cnc-table/
